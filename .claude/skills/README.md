# Skills from OpenMontage

These Claude Code skills come from https://github.com/calesthio/OpenMontage (commit 195eab2).
They are licensed under AGPL-3.0 (see OPENMONTAGE_LICENSE).

Some skills need API keys (HeyGen, ElevenLabs, BFL, etc.) or local tools such as FFmpeg.
The full OpenMontage video pipeline (Python tools, Remotion composer) is not included here.
To use it, clone the main repo.

# Skills from Ponytail

ponytail, ponytail-review, ponytail-audit, ponytail-debt, ponytail-gain and ponytail-help come from
https://github.com/DietrichGebert/ponytail (commit 96608e0), MIT license (see PONYTAIL_LICENSE).
Only the skills are copied. For the auto-activate hooks and status line, install the plugin:
/plugin marketplace add DietrichGebert/ponytail, then /plugin install ponytail@ponytail
