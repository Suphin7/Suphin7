# Skills from OpenMontage

These Claude Code skills come from https://github.com/calesthio/OpenMontage (commit 195eab2).
They are licensed under AGPL-3.0 (see OPENMONTAGE_LICENSE).

Some skills need API keys (HeyGen, ElevenLabs, BFL, etc.) or local tools such as FFmpeg.
The full OpenMontage video pipeline (Python tools, Remotion composer) is not included here.
To use it, clone the main repo.
